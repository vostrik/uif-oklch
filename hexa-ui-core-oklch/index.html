Hexa из одного цвета

Все 436 цветовых токенов Hexa пересобраны от одного --hx-base через oklch(from …). Тёмная тема больше не отдельная таблица соответствий: это та же таблица, где светлота каждого шага пропущена через одну кривую.

Транспонирование светлоты

Каждая точка — семантический токен Hexa: по оси X его L в светлой теме, по Y — L, которую дизайнеры вручную выбрали для тёмной. Линия — одна формула, которая заменяет эту таблицу.

L↔

Зеркало, а не инверсия. Ручная таблица Hexa почти точно ложится на отражение L относительно ≈0.63. Это не 1 − L: тёмный фон не чёрный (L 0.235), а основной текст не белый (L ≈ 0.93).

γ

Кривая растягивает поверхности. У белого края шаги Hexa в тёмной теме примерно вдвое шире, чем в светлой: тёмным уровням подложки нужно больше разницы по L. γ < 1 даёт это растяжение, при γ = 1 получается чистое зеркало.

C

Хрома не переносится, а пересчитывается. Она зависит от новой L через «колокол», поэтому тёмная подложка акцента остаётся насыщенной, а не серой.

±

Состояния переворачиваются сами. Hover в светлой — это L − 0.04. Знак задаёт тема (--hx-state-dir), поэтому в тёмной hover светлеет без отдельной таблицы.

max

Заливка в тёмной не темнеет. Для кнопок и бейджей берётся max(L, T(L)). Иначе жёлтый warning превратился бы в коричневый.

Контраст WCAG

Ключевые пары «текст на фоне», считается по фактически отрисованным цветам с учётом прозрачности. AA для обычного текста — 4.5, для границ и крупных элементов — 3.

Где генерация расходится с Hexa

Сравнение всех 436 токенов в обеих темах. Крупные расхождения почти все там, где сама ручная таблица Hexa нарушает свою же логику переворота: стоит решить, что из этого задумано.

Как это выглядит в коде

Фрагмент сгенерированного файла. Тёмная тема — это три строки.

/* единственный цвет */
:root { --hx-base: #4269E7; }

/* роль = шаг шкалы; L транспонируется темой, C пересчитывается по новой L */
--_r-red-50: calc((1 - var(--hx-dark)) * var(--hx-l-50)
       + var(--hx-dark) * clamp(0.18, calc(var(--hx-dk-floor)
       + var(--hx-dk-gain) * pow(1 - var(--hx-l-50), var(--hx-dk-gamma))), 0.97));
--role--red_50: oklch(from var(--hx-base)
       var(--_r-red-50)
       calc(c * var(--hx-red-k) * exp(-1 * pow((var(--_r-red-50) - var(--hx-red-peak)) / 0.3, 2)))
       calc(h + var(--hx-red-dh)));

/* семантика Hexa — одна таблица на обе темы */
--bg--danger_subtle--enabled: var(--role--red_50);

/* текст на заливке выбирается по её L */
--fg--on_accent: oklch(from var(--fill--accent--enabled)
       clamp(0.2, calc((l - 0.64) * -100), 1) calc(c * 0.12) h);

/* вся тёмная тема */
.theme-dark { --hx-dark: 1; --hx-state-dir: 1.3; color-scheme: dark; }
